
# Company Profile & Katalog Produk - AgriMandiri

## Deskripsi

Website Company Profile dan Katalog Produk berbasis web terintegrasi WhatsApp untuk AgriMandiri - perusahaan di bidang agribisnis.

## Fitur

- Responsif untuk semua perangkat
- Animasi halus dan modern
- Pencarian produk
- Filter produk berdasarkan kategori
- Detail produk
- Galeri gambar
- Form kontak terintegrasi WhatsApp
- Desain dengan warna yang nyaman

## Teknologi

- HTML5
- CSS3
- JavaScript
- WhatsApp API

## Instalasi

1. Clone repository ini
2. Buka index.html di browser
3. Atur nomor WhatsApp di js/whatsapp.js
