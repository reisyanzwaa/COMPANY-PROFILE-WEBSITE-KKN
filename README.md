# 🌿 KWT "BERSERI" - Company Profile Website

<img alt="KWT Berseri" src="img/logo/logo kwt.svg" width="120">

**Kelompok Wanita Tani "BERSERI"** adalah website company profile yang dikembangkan sebagai media informasi, promosi, dan pemasaran digital untuk Kelompok Wanita Tani (KWT) "BERSERI" yang berlokasi di Gang Kamarema RT 03, Dusun Danau Raya, Desa Persiapan Pinang Raya, Kecamatan Sangatta Selatan, Kabupaten Kutai Timur, Kalimantan Timur.

---

## 📋 **Deskripsi Proyek**

Website ini dibuat untuk mendukung program pemberdayaan perempuan dan ketahanan pangan keluarga melalui digitalisasi informasi dan promosi produk-produk unggulan KWT "BERSERI". Website ini menampilkan profil kelompok, produk unggulan, galeri kegiatan, serta informasi kontak yang terintegrasi dengan WhatsApp untuk memudahkan pemesanan produk.

---

## 🎯 **Fitur Utama**

| No | Fitur                           | Keterangan                                                                               |
| -- | ------------------------------- | ---------------------------------------------------------------------------------------- |
| 1  | **Halaman Beranda**       | Menampilkan banner slideshow, hero section, features, kategori, dan produk unggulan      |

| 3  | **Halaman Katalog**       | Menampilkan produk unggulan dengan fitur filter kategori dan search                      |
| 4  | **Halaman Galeri**        | Dokumentasi kegiatan dengan filter kategori (Kegiatan, Produksi, Panen)                  |
| 5  | **Halaman Kontak**        | Informasi alamat, email, WhatsApp, peta interaktif, dan jam operasional                  |
| 6  | **Halaman Detail Produk** | Informasi lengkap produk dengan pilihan varian rasa                                      |
| 7  | **Halaman Profil Diri**   | Profil pengembang website                                                                |
| 8  | **Integrasi WhatsApp**    | Memudahkan pemesanan produk melalui WhatsApp                                             |
| 9  | **Responsif Mobile**      | Tampilan optimal di desktop, tablet, dan smartphone                                      |

## 📱 **Halaman Website**

### 1. **Beranda (index.html)**

- Banner slideshow dengan 5 slide produk unggulan
- Hero section dengan deskripsi KWT "BERSERI"
- Features (4 keunggulan)
- Kategori produk (Jamur, Perikanan, Olahan)
- Produk unggulan dengan slot cards
- Testimoni pelanggan
- CTA Belanja Sekarang

### 2. **Profil (profil.html)**

- Sejarah dan perjalanan KWT "BERSERI"
- Visi dan Misi
- Struktur Organisasi IRTP "Dapur Produktif Makmur"
- Diagram Alir Proses Pengolahan

### 3. **Katalog (katalog.html)**

- Grid produk dengan gambar dan deskripsi
- Fitur filter kategori (Jamur, Pertanian, Perikanan, Peternakan, Olahan)
- Fitur search produk
- Tombol "Lihat Detail" dan "Pesan via WhatsApp"

### 4. **Galeri (galeri.html)**

- Filter kategori (Kegiatan, Produksi, Panen)
- 27 foto dokumentasi kegiatan
- Animasi grid gallery

### 5. **Kontak (kontak.html)**

- 4 Kartu informasi (Alamat, Email, WhatsApp, Jam Operasional)
- Peta interaktif (Google Maps & Waze)
- Tombol copy koordinat
- Tombol hubungi WhatsApp

### 6. **Detail Produk (detail_produk.html)**

- Gambar produk utama
- Pilihan varian rasa (Original, Balado, Coklat, Jagung Bakar)
- Spesifikasi produk
- Tombol pesan via WhatsApp
- Produk terkait

### 7. **Profil Diri (profil_diri_reisya.html)**

- Profil pengembang website
- Informasi pribadi
- Kontak dan sosial media
